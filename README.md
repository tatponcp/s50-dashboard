# S50 Options Dashboard

Dashboard สรุปภาพ SET50 Index Options แบบ End-of-Day สำหรับเทรดเดอร์ —
Open Interest รายสไตรค์ (มีมุมมอง 3 มิติ), Max Pain, PCR, ATM IV,
Expected Range และ OI เปลี่ยนแปลงรายสไตรค์

**เว็บจริง:** https://s50-dashboard.vercel.app

ข้อมูลอัปเดตอัตโนมัติทุกเย็นวันทำการโดย GitHub Actions
(ดึงจาก API สาธารณะของ TFEX หลังตลาดปิด) แล้ว Vercel deploy ให้เองทุก push
